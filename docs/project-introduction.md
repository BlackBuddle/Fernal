## 1. 주제 및 결과 요약

### 주제

바탕화면 위에 떠 있는 투명한 창 안에서 3D 식물 한 그루가 며칠에 걸쳐 자란다. 물, 영양제, 온도, 습도, 채광, 애정도 여섯 값이 가지 하나하나의 길이와 각도, 잎의 수와 크기를 정한다. 같은 씨앗(시드)에서 출발해도 돌보는 방식에 따라 다른 나무가 된다. 나무는 줄기에서 큰 가지, 작은 가지, 잔가지로 같은 규칙을 축척만 바꿔 반복하는 자기 닮음(프랙탈) 구조다. 해와 달은 실제 시각에 맞춰 창 위쪽을 가로지르고 온도와 채광은 그 지역의 오늘 날씨를 기본값으로 쓴다.

이 프로젝트는 Qt for Python으로 만들었다. 식물 장면 하나만 Qt Quick 3D(QML)이고 도구창·메뉴·트레이·설정·디버그 도구 등 나머지 UI는 전부 Qt Widgets 파이썬 코드다. 바인딩은 Qt 공식 바인딩인 PySide6를 썼다. PyQt6와 API가 거의 같아서(시그널 선언 이름과 import 경로 정도만 다르다) PyQt 기준으로 읽어도 구조가 그대로 통한다.

### 2.2 시스템 구성

순수 파이썬 계층(시뮬레이션, 골격 생성, 하늘 계산)과 Qt 계층(창, 장면, 도구창)을 나눴다. 순수 계층은 Qt 없이 테스트할 수 있다.

```
 sky.py (태양 위치, 날씨)       tools.py (Qt Widgets 도구창)
        │                              │ action 시그널
        ▼                              ▼
 sim.py (환경 시뮬레이션) ◀──── app.py (컨트롤러: QTimer, QThreadPool, 저장)
        │ Env, 활력                    │
        ▼                              ▼
 tree.py (골격 생성) ──▶ mesh.py (정점 배열) ──▶ PlantGeometry(QQuick3DGeometry)
                                                        │
                                Bridge(QObject 속성) ───┼──▶ Scene.qml (Qt Quick 3D)
                                                        ▼
                                          overlay.py (투명 QQuickView, 메뉴, 트레이)
```

1초마다 시뮬레이션이 한 단계 진행된다. 성장 매개변수가 의미 있게 바뀌면 골격을 다시 만들고 나이만 바뀌면 정점 배열의 길이와 굵기만 다시 계산한다.

### 2.3 환경 변수의 시간 변화

환경 상태는 물 $W$, 영양 $N$, 온도 $T$(°C), 습도 $H$, 채광 $L$, 애정도 $E$로 이루어진다. 온도를 뺀 값은 모두 0~1 범위다. 실제 시간 $h$시간이 지나면 다음처럼 바뀐다($\mathrm{clamp}$는 0~1로 자르는 함수).

$$T = T_{\text{out}} + \Delta T_{\text{heater}},\qquad \Delta T_{\text{heater}} \in [-10,\,10]$$

$$L = \min\!\big(R,\; f_{\text{day}}(e)\big),\qquad f_{\text{day}}(e) = \mathrm{clamp}\!\left(\frac{e+6}{12}\right)$$

여기서 $R$은 단파 일사량을 800 W/m²로 나눈 값이고 $e$는 태양 고도(도)다. 날씨를 아직 못 받았으면 $R = 0.7\max(0, \sin e)$로 대신한다.

$$W_{t+h} = \mathrm{clamp}\!\Big(W_t - h\,\big(0.01 + 0.02L + 0.001\max(0,\,T-20)\big)\Big)$$

$$N_{t+h} = N_t - \frac{0.1}{24}h,\qquad E_{t+h} = E_t - \frac{0.1}{24}h$$

$$H^{*} = \mathrm{clamp}\big(0.3 + 0.5W + 0.2H_{\text{out}} - 0.15L - 0.005(T-22)\big),\qquad H_{t+h} = H_t + (H^{*}-H_t)\min(1,\,0.5h)$$

물은 덥고 밝을수록 빨리 마르고 영양과 애정도는 하루에 0.1씩 줄어든다. 습도는 흙의 물과 바깥 습도를 따라가는 목표값 $H^*$로 서서히 다가가는 값이다. 사용자 행동은 값을 바로 올린다.

| 행동 | 효과 |
|---|---|
| 물 주기 | $W \mathrel{+}= 0.2$ |
| 영양제 | $N \mathrel{+}= 0.3$ |
| 스프레이 | $H \mathrel{+}= 0.15$ |
| 창에 마우스를 올리거나 클릭 | $E \mathrel{+}= 0.05$ |
| 온도 조절 슬라이더 | $\Delta T_{\text{heater}}$를 −10~+10 °C로 설정 |

### 2.4 활력과 성장 속도

각 변수 $x_i$가 적정 범위 $[a_i, b_i]$에서 벗어난 거리를 $d_i$라 하면 활력 $V$는 다음 가중 평균이다.

$$d_i = \max(a_i - x_i,\; x_i - b_i,\; 0),\qquad V = \mathrm{clamp}\!\left(\sum_i w_i \max\!\left(0,\; 1 - \frac{d_i}{\Delta_i}\right)\right)$$

| 변수 | 적정 범위 $[a_i, b_i]$ | 가중치 $w_i$ | 감쇠 거리 $\Delta_i$ |
|---|---|---|---|
| 물 | 0.4~0.8 | 0.25 | 0.4 |
| 영양 | 0.3~0.9 | 0.15 | 0.6 |
| 온도 | 17~27 °C | 0.20 | 10 °C |
| 습도 | 0.35~0.8 | 0.10 | 0.45 |
| 채광 | 0.3~1.0 | 0.20 | 0.7 |
| 애정도 | 0.3~1.0 | 0.10 | 0.7 |

식물의 나이 $A$(식물 시간)는 실제 시간보다 빠르거나 느리게 흐른다. 시간 배속을 $s$라 하면 다음과 같다.

$$\frac{dA}{dt} = s \cdot \exp\!\left(-\left(\frac{T-22}{10}\right)^{2}\right)\cdot(0.3 + 0.7L)\cdot V$$

온도 항은 22 °C에서 1로 가장 크고 12 °C와 32 °C에서 $1/e$로 떨어지는 종 모양이다. 밤($L=0$)에도 채광 항이 0.3으로 남아, 기본 환경에서 낮의 약 40% 속도로 계속 자란다. 첫 실행은 나이 48시간(어린 나무)과 배속 $s=8$에서 시작한다. 기본 환경의 낮이라면 시간당 약 5.8식물시간씩 자라서, 다 자란 나이(약 104시간)에 낮 기준 약 10시간이면 도달한다.

### 2.5 환경 값에서 성장 매개변수로

`tree.params_from`이 여섯 환경 값과 활력을 나무 모양을 정하는 매개변수로 바꾼다.

| 매개변수 | 식 | 의미 |
|---|---|---|
| 분지 계수 $b$ | $b = 1.5 + 2N$ | 마디마다 곁가지 수 |
| 길이 비 $\lambda$ | $\lambda = 0.6 + 0.25W$ | 가지 길이의 전체 축척 |
| 처짐 $\delta$ | $\delta = \mathrm{clamp}\!\left(\dfrac{0.2-W}{0.2}\right)$ | 물이 0.2 아래로 떨어지면 가지가 처짐 |
| 잎 밀도 $\rho$ | $\rho = H\cdot V$ | 잎 수 |
| 잎 크기 $\sigma$ | $\sigma = 0.5 + W$ | 잎 한 장의 크기 |
| 굴광성 세기 $\tau$ | $\tau = 0.1 + 0.5L$ | 햇빛 쪽으로 기우는 정도 |
| 열매 비율 $f$ | 열매 테마에서 $f = 0.3E$, 그 외 0 | 열매 수 |

굴광 방향 $\hat{\mathbf s}$는 그날 오후 1시의 태양 방향 단위벡터다($x$ 동쪽, $y$ 위, $z$ 남쪽).

### 2.6 줄기와 가지의 수학적 모델

나무는 순서(order)별 축으로 이루어진다. 0은 줄기, 1은 큰 가지, 2는 작은 가지, 3은 잔가지다. 각 축은 짧은 직선 마디(segment)의 사슬이다. 곁가지는 마디와 마디 사이의 매듭에서 나오므로, 모든 자식 마디의 시작점은 부모 마디의 끝점과 같다. 같은 규칙을 순서마다 축척만 바꿔 반복하므로 통계적으로 자기 닮은 구조가 된다.

**줄기 길이와 수관 위치.** 줄기 전체 길이는 다음과 같고($u$는 그 마디의 0~1 균등 난수), 아래쪽 약 28%는 곁가지 없는 맨 줄기다.

$$\ell_0 = 100\,(2.15 + 0.3u)\,(0.75 + 0.35\lambda)\ \text{cm},\qquad z_0 = 0.28 + 0.06\,(u - 0.5)$$

**곁가지 수.** 순서 $o$인 축의 매듭 하나에 붙는 곁가지 수는 다음과 같다.

$$n = \min\!\big(3,\; \lfloor p_o\, b\, m + U \rfloor\big),\qquad U \sim \mathcal{U}(0,1)$$

$p_o$는 순서별 계수(0.50, 0.36, 0.34, 0.32)이고 $m$은 축 끝 매듭 보정값이다(줄기 끝 1.4, 다른 축 끝 0.8, 그 외 1). $\lfloor x + U \rfloor$의 기댓값은 정확히 $x$이므로($x<3$일 때) 곁가지 수의 평균은 영양 $N$에 비례한다.

$$\mathbb{E}[n] = p_o\, m\,(1.5 + 2N)$$

**곁가지 길이.** 줄기에서 나온 큰 가지는 수관 안의 상대 위치 $r$(0은 수관 아래, 1은 꼭대기)에 따라 달걀 모양 윤곽을 따른다.

$$\ell_1 = 0.62\,\ell_0\,\frac{\lambda}{0.72}\,C(r)\,(0.8 + 0.4u),\qquad C(r) = 0.32 + 0.68\,\exp\!\left(-\left(\frac{r-0.3}{0.48}\right)^{2}\right)$$

더 작은 가지는 부모 축 길이에 순서별 비율 $k$(0.72, 0.62, 0.45)를 곱한다. 부모 축의 끝쪽($t \to 1$)에서 나온 가지일수록 짧다.

$$\ell_{o+1} = \ell_o\, k_{o+1}\,\frac{\lambda}{0.72}\,(1 - 0.5t)\,(0.75 + 0.5u)$$

$\ell$이 모두 $\lambda$에 비례하므로 물 $W$가 곧 나무 전체의 크기를 정하는 변수다.

**가지 각도와 배열.** 벌어짐 각 $\phi = 35°$를 기준으로 다음과 같다. 곁가지의 방위각은 황금각(약 137.5°)씩 돌아가며 배치해 잎차례처럼 고르게 퍼진다.

$$\theta = \min\!\big(70°,\; \theta_0 + 25°\,\delta\big),\qquad \theta_0 = \begin{cases}\phi\,(1.2 + 0.6u)(1 - 0.35r) & \text{줄기에서 나올 때}\\ \phi\,(1 + 0.6u) & \text{그 외}\end{cases}$$

$$\alpha_{k,j} = \alpha_0 + k\cdot 137.5° + j\cdot\frac{360°}{n}$$

**방향 갱신(굴광성과 처짐).** 마디가 하나 늘 때마다 진행 방향 $\mathbf d$는 무작위 휨, 위로 휘는 힘과 처지는 힘, 햇빛 쪽으로 당기는 힘을 더한 뒤 정규화한다.

$$\mathbf d' = \mathrm{normalize}\Big(\mathbf d + \beta_o(0.4+u)\,\mathbf w + \big(\kappa_{\text{rise}}(1-t) - \kappa_{\text{sag}}\,t^{1.5}\big)\hat{\mathbf y} + \gamma_o\,\tau\,\hat{\mathbf s}\Big)$$

$\beta_o$는 휨 크기(0.07~0.18), $\mathbf w$는 무작위 수직 방향, $\gamma_o$는 순서별 굴광 계수(0.06~0.10)다. 처짐 계수 $\kappa_{\text{sag}}$에는 $0.5\,\delta$가 더해져 물이 부족하면 가지 끝이 아래로 휜다. 굴광 힘이 마디마다 조금씩 쌓여 햇빛 쪽으로 완만하게 기운다. 줄기에는 위로 당기는 힘이 커서, 채광이 가장 강할 때도 가지 끝의 평균 기울기는 키의 약 6%에 그친다(2.8절 측정).

**굵기(파이프 모델).** 한 마디가 떠받치는 가지 끝의 수를 $n_i$라 하면 반지름은 다음과 같다. $j$는 축 안에서 마디 위치, $J$는 축의 마디 수다.

$$r_i = r_0\left(\frac{n_i}{n_0}\right)^{0.42}\left(1 - 0.22\,\frac{j}{J}\right),\qquad r_0 = 6\ \text{cm}$$

이는 갈라지는 지점에서 $r^{\Delta} = \sum_k r_k^{\Delta}$, $\Delta = 1/0.42 \approx 2.38$이 성립한다는 뜻이다. 레오나르도 다빈치의 가지 규칙($\Delta=2$)과 머리의 법칙($\Delta=3$) 사이 값이다.

**자라는 과정.** 마디는 태어난 나이 $A_b$부터 $T_g = \ell/v_o$시간 동안 smoothstep 곡선으로 길어진다($v_o$는 순서별 속도로 시간당 2.45~3.0 cm).

$$g(A) = S\!\left(\mathrm{clamp}\!\left(\frac{A - A_b}{T_g}\right)\right),\qquad S(x) = 3x^2 - 2x^3$$

다음 마디는 부모가 85% 자랐을 때, 곁가지는 90% 자란 뒤 짧은 지연을 두고 태어난다. 굵기는 그 마디가 떠받치는 가지들이 자란 비율을 따라 나중에 굵어진다(2차 생장). 그래서 어린 나무의 줄기는 가늘다.

$$r(A) = r\cdot\max\!\left(0.3,\ \left(\frac{\sum_{k\in\text{subtree}} g_k(A)}{|\text{subtree}|}\right)^{0.45}\right)$$

### 2.7 나뭇잎과 열매의 수학적 모델

잎은 잔가지(가중치 1.0), 작은 가지(0.8), 큰 가지(0.45), 줄기 위쪽 70%(0.8)에 붙는다. 길이 $\ell_{\text{seg}}$인 마디 하나에 붙는 잎 수의 기댓값은 다음과 같다.

$$\mathbb{E}[n_{\text{leaf}}] = \frac{2.2}{3}\,\rho\, w_o\,\ell_{\text{seg}}\,(0.55 + 0.9t)\,(0.45 + 1.1u)$$

마디당 최대 16장이고 약 8%의 마디는 일부러 잎 없이 남겨 가지가 비쳐 보이게 한다. 나무 전체가 4,800장을 넘으면 모든 마디에 같은 비율 $\min(1,\,4800/\sum)$을 곱해 고르게 줄인다. 잎 밀도 $\rho = HV$가 곱해지므로 잎 수는 습도와 활력에 정비례하는 셈이다.

잎은 받치는 마디가 60~100% 자란 뒤 0.3~1.8시간 지나 태어나고 5시간에 걸쳐 펴진다. 화면에 보이는 잎의 한 변 길이는 다음과 같다.

$$s_{\text{leaf}}(A) = 13\ \text{cm}\times\sigma\times c\times S\!\left(\mathrm{clamp}\!\left(\frac{A - A_{\text{leaf}}}{5}\right)\right),\qquad c \in [0.7,\, 1.3]$$

일찍 난 잎은 작게($c$의 폭을 좁게) 두어 수관 안쪽의 그늘잎처럼 보이게 했다. 열매 테마에서는 잎마다 고정 난수 $u$를 하나 두고 $u < 0.12f = 0.036E$인 잎 아래 3 cm에 열매가 달린다. 그래서 열매 수는 애정도에 정비례하고 애정도가 오르면 기존 열매는 그대로 두고 새 열매만 늘어난다.

### 2.8 변수와 줄기·잎의 상관관계

위 식을 정리하면 각 변수는 다음 경로로 줄기와 잎에 영향을 준다.

| 변수 | 줄기(가지) | 나뭇잎 | 그 밖의 효과 |
|---|---|---|---|
| 물 $W$ | $\lambda$를 통해 모든 가지 길이에 비례, 0.2 미만이면 처짐 | 잎 크기 $\sigma = 0.5+W$ | 활력의 25% |
| 영양 $N$ | 곁가지 수 $\mathbb{E}[n] \propto 1.5+2N$ | 가지가 늘어난 만큼 잎도 늘어남 | 활력의 15% |
| 습도 $H$ | 영향 없음 | 잎 수 $\propto H\cdot V$ | 물과 바깥 습도를 따라감 |
| 채광 $L$ | 굴광 세기 $\tau = 0.1+0.5L$ | 활력을 통해 잎 수에 간접 영향 | 성장 속도 $(0.3+0.7L)$ |
| 애정도 $E$ | 영향 없음 | 열매 수 $\propto E$ | 활력의 10% |
| 온도 $T$ | 영향 없음 | 활력을 통해 잎 수에 영향(역U자) | 성장 속도에 종 모양으로 작용 |

이 관계가 실제 생성 결과에서도 나타나는지 확인하려고 변수 하나만 바꾸고 나머지는 기본값(물 0.6, 영양 0.5, 22 °C, 습도 0.5, 채광 0.6, 애정도 0.5)에 둔 채 다 자란 나무를 시드 5개로 만들어 평균을 냈다. 기울기는 태양을 동쪽에 두었을 때 가지 끝 평균 $x$를 키로 나눈 값이다.

| 변수(범위) | 가지 수 | 잎 수 | 키(cm) | 폭(cm) | 기울기 | 열매 수 |
|---|---|---|---|---|---|---|
| 물(0.1→1.0) | 554→1,457 (r=+0.98) | 1,478→4,573 (+0.97) | 272→344 (+0.99) | 228→307 (+0.91) | 변화 작음 | 없음 |
| 영양(0→1) | 347→1,500 (+0.97) | 1,082→4,549 (+0.95) | 309→280 (−0.67) | 203→236 | 변화 작음 | 없음 |
| 습도(0.1→0.9) | 변화 없음 | 729→4,798 (+0.96) | 변화 없음 | 변화 없음 | 변화 없음 | 없음 |
| 채광(0→1) | 변화 없음 | 3,550→3,882 (+0.79) | 313→320 (+0.97) | 266→243 (−1.00) | +0.006→+0.064 (+1.00) | 없음 |
| 애정도(0.1→0.9, 열매 테마) | 변화 없음 | 3,773→3,882 | 변화 없음 | 변화 없음 | 변화 없음 | 15→127 (+1.00) |
| 온도(5→40 °C) | 변화 없음 | 3,100→3,882→3,100 (역U자) | 변화 없음 | 변화 없음 | 변화 없음 | 없음 |

괄호 안은 변수와 결과의 피어슨 상관계수다. 식에서 예상한 방향과 모두 일치한다. 영양이 0.8 이상이면 가지 수가 상한(1,500)에 걸려 늘지 않고 위쪽 가지가 덜 만들어져 키가 오히려 줄어든다. 채광이 강하면 나무가 해 쪽으로 기울면서 위로 곧게 서서 폭이 좁아지는 효과도 있다.

### 2.9 바람과 하늘

**바람.** 바람은 GPU의 정점 셰이더(`wind.vert`)에서 계산하므로 파이썬은 프레임마다 아무 일도 하지 않는다. 정점마다 흔들림 위상 $\psi$와 무게 $w$(뿌리 0, 가지 끝 1)를 미리 넣어 두고 시간 $t$에 따라 다음만큼 옮긴다($\varpi$는 정점 위치에서 나온 공간 위상, $s_w$는 바람 세기).

$$\Delta\mathbf x = \hat{\mathbf w}\, G(t)\,(0.6 + 4.4\,s_w)\,w,\qquad G(t) = 0.65\sin(0.9t+\varpi) + 0.25\sin(2.3t + 1.7\varpi + 0.35\psi) + 0.10\sin(4.1t + \psi)$$

세 진동수가 모두 0.1의 배수이므로 시계를 $2\pi/0.1 \approx 62.8$초 주기로 되감아도 움직임이 끊기지 않는다.

**하늘.** 태양 고도 $e$는 NOAA 근사식으로 구하며 위도 $\varphi$, 태양 적위 $\delta_\odot$, 시간각 $h_a$에 대한 식은 다음과 같다.

$$\sin e = \sin\varphi\,\sin\delta_\odot + \cos\varphi\,\cos\delta_\odot\,\cos h_a$$

해가 지평선 위에 있으면 해 원반을, 아래에 있으면 반대편의 달 원반을 창 위쪽 띠에 그린다. 조명은 고도 −6°~+6° 구간에서 따뜻한 햇빛과 푸른 달빛 사이를 섞는다.

### 3.3 파이썬과 QML을 잇는 브리지

파이썬의 `Bridge(QObject)`가 해의 고도·방위각, 낮밤 계수, 테마 색, 활력, 바람 세기, 카메라 각도 등 18개 값을 `Property`로 노출한다. 값이 바뀔 때만 `<이름>Changed` 시그널을 보내고 QML은 이 속성에 바인딩되어 있어 자동으로 다시 그려지는 구조다. `setContextProperty`로 브리지와 지오메트리 3개, 텍스처 폴더 경로를 장면에 넘긴다. QML에서 파이썬을 부르는 일은 없고 데이터는 파이썬에서 QML로 한 방향으로만 흐른다.

### 3.4 절차적 지오메트리: `QQuick3DGeometry`

가지·잎·열매는 각각 `QQuick3DGeometry`를 상속한 `PlantGeometry` 하나로 그리는 방식이다. numpy로 만든 정점 배열을 `QByteArray`로 바꿔 `setVertexData`, `setIndexData`로 넘긴다. 정점 하나는 40바이트이고 위치(12), 법선(12), 텍스처 좌표(8), 바람 정보(8)를 담는다. 잎 수천 장을 메시 하나로 합쳐 드로우콜을 줄였다. 다 자란 나무(정점 약 4.4만 개)의 배열 계산은 약 7 ms, GPU 업로드는 약 4 ms다.

### 4.2 해석

- **물이 가장 큰 영향을 준다.** 길이 비 $\lambda$가 모든 가지 길이에 곱해지고 잎 크기까지 정하므로 가지 수, 잎 수, 키, 폭이 모두 물과 0.9 이상 상관을 보인다. 실제 식물에서 수분이 생장을 가장 크게 좌우하는 것과 같은 방향이다.
- **줄기와 잎이 따로 조절된다.** 영양은 곁가지 수(줄기 구조)를, 습도와 활력은 잎 수를 정한다. 그래서 "가지는 많은데 잎이 성긴 나무"나 "가지는 적은데 잎이 무성한 나무"가 모두 가능하다. 사용자가 어떻게 돌봤는지가 모양에 그대로 드러난다.
- **비대칭은 두 가지에서 온다.** 마디마다 다른 난수 휨과 길이, 그리고 해 쪽으로 쌓이는 굴광성이다. 채광과 기울기의 상관계수는 1.00이고 기울기는 키의 6% 안팎으로 완만하다.
- **온도는 모양이 아니라 속도를 바꾼다.** 성장 속도는 22 °C에서 가장 빠르고 5 °C나 40 °C에서는 20분의 1 아래로 떨어진다. 극단 온도에서는 활력이 낮아져 잎도 20% 정도 줄어든다.
- **한계도 측정으로 드러났다.** 성장 35~50% 구간에서는 가지 끝의 약 40~50%가 잎 없이 드러난다. 잎은 받치는 가지가 60~100% 자란 뒤에야 돋고 다 펴지는 데 5시간이 더 걸리기 때문이다. 다 자라면 0~1%로 사라진다. 또 영양이 매우 높으면 가지 수 상한에 걸려 위쪽이 잘린다.

### 4.3 개발 과정에서 해결한 문제

| 문제 | 해결 |
|---|---|
| 투명 창에서 글로우가 보이지 않음 | 글로우 혼합을 가산 방식으로 바꾸고 여러 단계 글로우를 켰다. |
| 첫 나무가 막대에 쏠린 수관처럼 보임 | 2D 미리보기로 확인한 뒤 끝 분기 모델을 축 사슬 모델로 바꾸고 굴광성을 약하게 했다. |
| 줄기 마디마다 굵기 단차 | 각 마디의 끝 반지름을 가장 굵은 자식의 시작 반지름에 맞췄다. |
| 기본 렌더 스레드에서 첫 화면이 뜨지 않음 | 파이썬에서 창 이벤트를 재정의하면 렌더 스레드와 엇갈려 멈추는 것을 재현했고, GUI 스레드 렌더링으로 피했다. |
| 날씨 응답의 NaN이 상태 파일을 깨뜨릴 수 있음 | 유한한 값만 받도록 검사하고 테스트를 추가했다. |
| 종료 중 네트워크 요청이 남으면 프로세스가 남음 | 마지막 저장 후 즉시 종료하도록 바꿨다(0.08초 안에 종료). |
| 바람이 1시간마다 한 번 튐 | 시계 주기를 바람 진동수의 공통 주기(62.8초)로 바꿨다. |

### 4.4 기대효과

- **조용한 동반자.** 일하는 화면 한쪽에서 식물이 자라면서 잠깐씩 돌보는 습관을 만들면서도 자원을 적게 쓰고 클릭 통과 모드가 있어 작업을 방해하지 않는다.
- **교육 자료.** 재귀 가지치기, 파이프 모델, 굴광성, 황금각 잎차례, 2차 생장 같은 식물 형태학 개념을 수식과 실시간 결과로 함께 보여 준다. 변수 하나를 바꿔 결과를 바로 확인할 수 있어 프로그래밍과 생물 수업 실습에 쓸 수 있다.
- **Qt for Python 활용 예시.** 투명 3D 오버레이, 파이썬에서 만든 지오메트리, QML 브리지, Qt Widgets 커스텀 페인팅, 스레드와 시그널 처리를 한 프로그램에서 보여 준다. 시뮬레이션과 화면이 분리되어 있어 다른 식물 모델이나 UI로 바꾸기 쉽다.

## 5. 향후 연구과제

1. **잎과 가지의 성장 동기화.** 잎이 가지 성장의 40~50% 시점부터 돋게 하거나 모든 가지 끝에 잎을 먼저 달아, 성장 중간의 맨 가지 끝 비율을 10% 아래로 낮춘다.
2. **가지 수 예산의 우선순위.** 너비 우선 생성 대신 줄기와 큰 가지를 먼저 확보하는 순서로 바꿔, 영양이 많을 때 위쪽이 잘리는 문제를 없앤다. 잎이 1만 장을 넘는 나무에는 GPU 인스턴싱과 거리별 세부 단계(LOD)를 적용하는 것이 다음 단계다.
3. **렌더 스레드 복원과 전력 절약.** 창 이벤트 재정의를 이벤트 필터로 바꿔 Qt 기본 렌더 스레드를 되살린다. 골격 생성도 작업 스레드로 옮길 대상이다. 창이 가려지거나 오래 쓰지 않을 때 프레임 수를 낮춰 노트북 배터리 소모를 줄인다.
4. **생물학적 모델 정교화.** 실제 날짜에 따른 계절 변화(단풍과 낙엽), 광합성량에 따른 탄소 분배, 흙과 뿌리 모델 등 기능-구조 식물 모델(FSPM) 요소를 더한다.
5. **상호작용 확장.** 물 주기 애니메이션, 소리, 여러 그루를 키우는 정원, 시드 공유, 디버그 조정값과 실제 돌봄 기록의 분리 저장.
6. **배포 개선.** 설치 파일 코드 서명(SmartScreen 경고 제거), 자동 업데이트, macOS와 Linux 지원.
7. **사용자 연구.** 실제 사용자가 얼마나 자주 돌보는지, 작업 집중도와 기분에 어떤 영향을 주는지 측정한다.

## 부록: 실행과 구성

실행 방법은 설치 파일과 소스 실행 두 가지다.

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\pythonw -m fernal
```

| 파일 | 역할 |
|---|---|
| `fernal/sim.py` | 환경 변수의 시간 변화, 활력, 성장 속도, 상태 저장 |
| `fernal/tree.py` | 시드와 매개변수로 가지 골격·잎·열매 위치 생성 |
| `fernal/mesh.py` | 골격을 정점 배열로 변환, `PlantGeometry` |
| `fernal/sky.py` | 태양 위치, Open-Meteo 날씨와 도시 검색 |
| `fernal/overlay.py` | 투명 창, 브리지, 메뉴, 트레이 |
| `fernal/app.py` | 컨트롤러: 타이머, 스레드, 도구 연결, 저장 |
| `fernal/tools.py`, `fernal/debug_panel.py` | Qt Widgets 도구창과 디버그 도구 |
| `fernal/qml/Scene.qml`, `fernal/qml/shaders/` | Qt Quick 3D 장면과 GLSL 셰이더 |
| `packaging/` | PyInstaller와 Inno Setup 설치 파일 빌드 |
